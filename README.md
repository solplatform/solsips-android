# SolSIP

Open-source SIP softphone for Android, based on [Linphone](https://www.linphone.org/).

SolSIP is a lightweight VoIP and video client that works with SIP servers (including Flexisip).

## Features

- Audio and video calls over SIP
- Compatible with Flexisip and other standard SIP servers
- Built with Kotlin
- Open source (GPLv3)
